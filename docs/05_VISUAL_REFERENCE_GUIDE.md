# 05 — Visual Reference Guide

## Statut

La référence visuelle fournie automatiquement est la principale inspiration de composition. Elle doit être étudiée avant reconstruction.

Elle n’est pas une maquette à reproduire pixel par pixel.

## À reprendre

- force du Hero ;
- grande photographie ;
- message immédiatement visible ;
- contraste marqué ;
- forte présence de marque ;
- hiérarchie claire ;
- alternance clair / sombre ;
- composition plus vivante ;
- sensation de véritable entreprise de terrain.

## À ne pas reprendre

- textes ;
- marque ;
- logo ;
- statistiques ;
- grues ;
- silhouettes ;
- engrenages ;
- motifs spécifiques ;
- découpe diagonale reconnaissable ;
- cartes de services identiques ;
- pictogrammes propriétaires.

## Traduction ONE X ENERGY

Remplacer l’univers construction lourde par :

- câblage ;
- tableaux électriques ;
- interventions ;
- installations ;
- techniciens ;
- apprenants ;
- matériels électriques.

## Hero recommandé

Deux configurations acceptables :

### Option A — photo plein fond
- photographie immersive ;
- overlay bleu nuit maîtrisé ;
- contenu blanc ;
- CTA orange.

### Option B — composition sombre + photo
- grand bloc bleu nuit ;
- contenu à gauche ;
- photographie dominante à droite ;
- séparation intégrée, pas de card.

Choisir selon les vrais médias.

## Header

- logo visible ;
- navigation claire ;
- CTA ;
- hauteur maîtrisée ;
- excellent comportement tablette.

## Rythme de l’accueil

1. Hero
2. présentation courte de ONE X ENERGY
3. électrification
4. formation
5. matériels
6. réalisations si disponibles
7. valeurs
8. contact
9. footer

Ne pas créer de statistiques sans vraies données.

## Critère de réussite

Un visiteur doit comprendre immédiatement : entreprise technique, électricité, formation, matériels, contact.
