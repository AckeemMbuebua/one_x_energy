# 02 — Editorial Guide

## 1. Objectif

Le contenu doit donner l’impression d’avoir été écrit par une organisation technique qui connaît son métier, pas par un générateur de texte marketing.

## 2. Ton

Utiliser :

- phrases plutôt courtes ;
- verbes concrets ;
- vocabulaire métier compréhensible ;
- formulations factuelles ;
- bénéfices réalistes ;
- titres précis.

Acceptable :

> Nous intervenons sur les installations électriques domestiques et commerciales, de l’étude à la mise en service.

À éviter :

> Nous révolutionnons l’énergie grâce à des solutions innovantes et sur mesure pour bâtir un avenir meilleur.

## 3. Registre

Employer « nous » pour ONE X ENERGY et « vous » pour le visiteur. Éviter le tutoiement.

## 4. Mots à éviter par défaut

- révolutionner ;
- visionnaire ;
- leader ;
- meilleur ;
- numéro un ;
- excellence ;
- exceptionnel ;
- incomparable ;
- innovation ;
- transformation ;
- avenir ;
- sur mesure ;
- 360° ;
- premium ;
- expertise inégalée ;
- partenaire de confiance.

## 5. Titres

Préférer :

- `Installations électriques pour bâtiments`
- `Se former à l’électricité bâtiment`
- `Matériels pour vos installations électriques`

Éviter :

- `L’énergie qui transforme votre quotidien`
- `L’avenir commence ici`
- `Une expertise sans limites`

## 6. CTA autorisés

- Nous contacter
- Demander un devis
- Appeler ONE X ENERGY
- Écrire sur WhatsApp
- Découvrir nos services
- Voir les formations
- Voir les matériels
- Voir les réalisations

## 7. Règles factuelles

Aucune statistique, témoignage, partenaire, prix, programme de formation, stock ou réalisation ne doit être inventé.

## 8. Formations

Formulation autorisée :

> ONE X ENERGY propose des formations techniques de base et avancées en électricité bâtiment.

Ne pas préciser durée, modules, certificat, tarif ou calendrier sans source.

## 9. Matériels

Formulation autorisée :

> Câbles, interrupteurs, disjoncteurs, luminaires, tableaux électriques et autres équipements.

Ne pas promettre le stock.
