# 00 — Project Brief

## 1. Projet

**ONE X ENERGY Organization** souhaite disposer d’un site vitrine professionnel présentant clairement ses trois domaines d’activité.

La V1 doit être une présence web institutionnelle crédible, claire, visuelle et facilement consultable sur mobile.

## 2. Domaines d’activité

### 2.1 Électrification des bâtiments

- étude des installations électriques ;
- conception ;
- réalisation d’installations électriques domestiques ;
- réalisation d’installations électriques commerciales ;
- mise en conformité ;
- maintenance ;
- dépannage des installations existantes.

### 2.2 Formation en électricité bâtiment

Formations techniques :

- de base ;
- avancées.

Publics mentionnés :

- jeunes ;
- étudiants ;
- techniciens ;
- professionnels souhaitant se spécialiser.

### 2.3 Vente de matériels et équipements électriques

Distribution notamment de :

- câbles ;
- interrupteurs ;
- disjoncteurs ;
- luminaires ;
- tableaux électriques ;
- autres équipements électriques.

## 5. Objectifs de la V1

Le site doit permettre à un visiteur de :

1. comprendre en quelques secondes ce que fait ONE X ENERGY ;
2. distinguer clairement les trois domaines d’activité ;
3. comprendre les prestations électriques proposées ;
4. découvrir l’offre de formation sans inventer de programme ;
5. comprendre que du matériel électrique est disponible ;
6. voir des réalisations uniquement si des médias réels sont disponibles ;
7. contacter facilement l’organisation ;
8. accéder au site correctement sur mobile, tablette et desktop.
